Key

Absolute Divergence The difference in °F between the sensor reading and simulated temperature at the current timestamp.
Threshold Fault Detection Green: divergence under 2°F. Yellow: divergence exceeds 2°F. Red: the sliding window average (last 30 readings) exceeds the threshold.
Threshold The °F limit for the sliding window average. If the average divergence over the last 30 readings exceeds this value, a fault is triggered. Editable in real time.
Simulated Temperature The baseline temperature used as the second data source. Editable in real time to test fault detection at different divergence levels.
